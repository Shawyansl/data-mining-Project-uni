# تمرین تحلیل بازار املاک

جریان مستقل املاک: آگهی‌های عمومی شیپور → CSV → تحلیل Pandas → جدول‌های جداگانه در PostgreSQL → داشبورد اختصاصی Grafana. این تمرین برای مشاوران املاک و سرمایه‌گذاران، شاخص‌های مقایسه‌ای محله‌ها و نامزدهای قیمت غیرعادی را نمایش می‌دهد.

## اجرا

از ریشه‌ی پروژه:

```bash
cp .env.example .env
docker compose up -d db grafana
```

برای دریافت حداکثر یک صفحه از هر دسته و تحلیل آن:

```bash
python sheypoor_scraper.py --mode both --pages 1 --output real_estate/sheypoor_properties.csv
docker compose --profile tools run --rm analytics-real-estate --csv /input/real_estate/sheypoor_properties.csv
```

می‌توان URL یک دسته‌بندی عمومی دیگر شیپور را با --url داد. اسکریپر ابتدا robots.txt را می‌خواند و صفحه‌هایی را که مجاز نیستند واکشی نمی‌کند. تعداد صفحه، مکث و محدودیت دسترسی سایت روی پوشش داده اثر می‌گذارد.

داشبورد «بازار املاک | فروش و اجاره» در پوشه‌ی Real-estate market ساخته می‌شود. گزارش‌ها در reports/real_estate/ قرار می‌گیرند. آگهی‌های خودرو در جدول‌های خودرو می‌مانند؛ املاک در real_estate_listing_snapshots و نمای جاری real_estate_listings_current ذخیره می‌شوند. هر دو از پایگاه car_market استفاده می‌کنند، اما جدول و datasource جدا دارند.

## روش و محدودیت‌ها

- فروش و اجاره جدا تحلیل می‌شوند. فروش بر مبنای قیمت هر متر مربع مقایسه می‌شود.
- برای اجاره، ودیعه و اجاره‌ی ماهانه جدا می‌مانند؛ تبدیل ودیعه به اجاره با نرخ فرضی انجام نمی‌شود.
- baseline بر میانه‌ی آگهی‌های هم‌نوع، هم‌شهر و هم‌محله، با متراژ حداکثر ۲۵٪ اختلاف و اتاق مشابه (اگر ثبت شده باشد) بناست. حداقل دو همتا لازم است؛ اگر نمونه‌ی هم‌محله‌ای کم باشد، برآورد عمداً خالی می‌ماند.
- قیمت توافقی، قیمت خالی، اجاره‌ی ماهانه‌ی کمتر از ۱۰۰ هزار تومان، ودیعه‌ی کمتر از یک میلیون تومان و اجاره‌ی روزانه از تخمین ماهانه حذف می‌شوند. تخمین‌ها قیمت پیشنهادی آگهی‌اند، نه قیمت معامله.
- پرچم غیرعادی از modified z-score مقاوم بر قیمت هر متر/اجاره‌ی ماهانه‌ی هر متر نسبت به همتاهای همان گروه به دست می‌آید؛ حد پیش‌فرض ۳٫۵ و حداقل چهار همتای قیمت‌دار است؛ با داده‌ی فعلی ممکن است هیچ پرچمی تولید نشود. این پرچم برای بازبینی است و به‌تنهایی دلیل کلاهبرداری یا زیرقیمت بودن نیست.
- محله و ویژگی‌های ملک فقط وقتی تحلیل می‌شوند که منبع در کارت آگهی نشان دهد. پوشش، تعداد همتا و محدودیت نمونه را همراه خروجی بخوانید.
- این baseline قابل توضیح است، نه مدل ML آموزش‌دیده. کیفیت استخراج، دسته‌بندی محله و تعداد نمونه روی نتیجه اثر دارد.

برای خاموش کردن سرویس‌ها: docker compose down. حذف volume با docker compose down -v تاریخچه‌ی هر دو حوزه را پاک می‌کند.
