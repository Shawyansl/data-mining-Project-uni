# داشبورد قیمت خودروهای کارکرده

جریان داده: CSV باما → پاک‌سازی و تحلیل با Pandas → PostgreSQL → Grafana.
اسکریپت Pandas چهار نمودار PNG و دو خلاصه CSV در reports/ می‌سازد.

## اجرا

از ریشه‌ی پروژه:

```bash
cp .env.example .env
```

رمزهای داخل .env را عوض کن، سپس:

```bash
docker compose up -d db grafana
docker compose --profile tools run --rm analytics --csv /input/cars_test.csv
```

Grafana روی http://localhost:3000 باز می‌شود. داشبورد «بازار خودروهای کارکرده | Bama» خودکار ساخته می‌شود. نام کاربری و رمز از .env خوانده می‌شوند.

بعد از ساخت CSV تازه با scraper، فرمان analytics را دوباره اجرا کن. تاریخچه‌ی snapshotها نگه‌داری می‌شود و داشبورد جاری آخرین رکورد هر آگهی را نمایش می‌دهد.

برای خاموش‌کردن سرویس‌ها: docker compose down
برای پاک‌کردن تاریخچه‌ی PostgreSQL: docker compose down -v

## تفسیر برآورد قیمت

- قیمت توافقی، کمتر از ۱۰۰ میلیون تومان و کارکرد غیرواقعی در محاسبه قیمت وارد نمی‌شود.
- baseline قیمت منصفانه میانه‌ی همتاهای همان واریانت، سال با اختلاف حداکثر یک سال، وضعیت صفر/کارکرده و کارکرد نزدیک است.
- حداقل دو آگهی همتا لازم است؛ زیرقیمت یعنی حداقل ۱۵٪ ارزان‌تر از این baseline.
- این یک baseline شفاف است، نه مدل ML آموزش‌دیده. تعداد نمونه و همتاها را کنار نتایج ببین. فایل فعلی ۴۴ آگهی دارد و ممکن است بعضی واریانت‌ها برآورد نداشته باشند.
